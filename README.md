# GITHUB USER ACTIVITY

JavaScript solution for [GitHub User Activity](https://roadmap.sh/projects/github-user-activity) from [roadmap.sh](https://roadmap.sh/).

## How to run

Run the following commands:

```bash

# Run on console
npm run start

# Fetch the recent activity of a GitHub user
github-activity >> <username>

# Replace <username> with the GitHub user, like the example below
github-activity >> kamranahmedse

```
